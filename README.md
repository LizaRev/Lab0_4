# Lab_04

## M1 — HTTP-сервер

Реалізовано HTTP-сервер на Node.js з використанням `node:http`.

Реалізовано:

* роздачу production-файлів клієнта;
* `GET /api/rooms`;
* `POST /api/rooms`;
* `GET /health`;
* захист від path traversal;
* обмеження розміру тіла POST-запиту;
* конфігурацію через змінні середовища;
* graceful shutdown при `SIGINT` та `SIGTERM`;
* proxy для `/api` та `/ws` у Vite.

## M4 — Надійність і backpressure

Реалізовано:

* обмеження частоти повідомлень на WebSocket-з'єднання;
* обмеження розміру повідомлення;
* обмеження кількості гравців у кімнаті;
* обмеження кількості кімнат;
* обробку повільних клієнтів через `bufferedAmount`;
* heartbeat для перевірки активності WebSocket-з'єднання.

### Event loop

Node.js виконує JavaScript-код в одному потоці. Основні фази event loop:

* Timers;
* Pending callbacks;
* Poll;
* Check;
* Close callbacks.

Синхронний блокуючий код затримує виконання інших операцій event loop.

Для демонстрації використано блокування приблизно на 300 мс через `/api/slow`.

### Backpressure

Потокове передавання файлів через `pipeline()` дозволяє не завантажувати весь файл у пам'ять сервера.

Backpressure було перевірено під час завантаження синтетичного файлу розміром 200 MB у M3.
